# Playbook

Read [[agent/DISCLAIMER]] and [[agent/TONO]] first.

## Goal
Turn a case into 2–5 vault options, each with a source, for a **clinician to review with the patient**.

## Order
1. Red flags / referral.
2. Condition index: [[indexes/POR-CONDICION]]
3. Matching domain.
4. Short answer + Source block.

No prescriptions, no personal doses, no needling instructions, do not stop drugs.
