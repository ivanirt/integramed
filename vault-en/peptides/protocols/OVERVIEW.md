# Protocols overview (concepts only)

Summarized from the book’s chapter *themes* (admin, reconstitution, cycling, stacking) without copying procedures.

## Administration families

| Family | Typical use in this catalog | Agent note |
|---|---|---|
| Subcutaneous | Many research peptides, some GLP-1 pens | Clinician or labeled device only |
| Intramuscular | Some neurotrophics / IGF discussion | Not DIY content |
| Intranasal | Semax, Selank, some DSIP talk | Formulation-specific |
| Oral / tablet | Some bioregulators, MK-677, some GLP-1 tablets | Bioavailability varies wildly |
| Topical | GHK-Cu skin talk | Separate from systemic |

## Reconstitution (do not execute here)

Lyophilized peptides are mixed with a sterile diluent under aseptic technique. The agent should **not** walk through volumes, BAC water ratios, or syringe math. Point to the product insert or a clinician.

Storage themes in public literature: cold chain for reconstituted vials, avoid freeze–thaw and vigorous shaking. Exact times are product-specific.

## Cycling (concept)

“On / off” blocks are discussed to limit receptor desensitization (GH secretagogues) or cost. There is **no universal cycle**. Approved chronic drugs (e.g. some GLP-1s) follow the label, not a bodybuilding calendar.

## Safety monitoring themes

Glucose, resting HR, injection-site reactions, gallbladder symptoms (incretins), blood pressure, sleep, mood, IGF-1 / thyroid if on secretagogues. Always clinician-directed.
