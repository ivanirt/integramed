# Playbook

Leer [[agent/DISCLAIMER]] y [[agent/TONO]] primero.

## Objetivo
Pasar un relato a 2–5 opciones de lectura del vault, cada una con fuente, para que el **medico las revise con el paciente**.

## Orden
1. Alarmas / derivacion.
2. Condicion: [[indexes/POR-CONDICION]]
3. Dominio que encaje.
4. Respuesta breve + bloque Fuente.

No recetes, no des miligramos para ti, no indiques pinchazos, no pares farmacos.
