# Playbook

Cargar disclaimer primero.

## Entrevista
1. Tejido o enfermedad (sangre, cerebro, piel, hueso, vaso, hígado, páncreas).
2. ¿Busca entender ciencia, ensayo clínico, o “una clínica me ofreció esto”?
3. Trasplante previo, cáncer activo, inmunosupresión.

## Salida
- Tipo(s) de célula que el libro trata para ese sistema
- Qué pregunta experimental cubre el capítulo (aislamiento / diferenciación / injerto *en modelos*)
- Evidencia humana actual: diferir a clínico; no inventar indicación
- Si piden protocolo de lab: negar y citar que el PDF es copyright + uso institucional

Ranking: correspondencia de tejido alta; oferta comercial no regulada = veto.
