# Stack patterns (literature / community, not protocols)

Always check interactions. Stacks multiply risk.

| Pattern | Typical pairing talk | Caution |
|---|---|---|
| Injury | BPC-157 + TB-500 | Unapproved; bleeding / tumor theoretical debates |
| GH pulse | Ipamorelin + Mod-GRF (1-29) | Glucose, edema, carpal tunnel, cancer hx |
| GH long | CJC-1295 DAC ± GHRP | Overlap with MK-677 / Tesamorelin |
| Incretin | Semaglutide or Tirzepatide ± amylin analog (cagrilintide trials) | Prescriber titration only; GI, gallbladder |
| Skin | GHK-Cu topical ± systemic repair peptides | Copper load if high-dose systemic |
| Anxiolytic + focus | Selank + Semax | Origin products vary; BP / stimulation |
| Immune reset talk | Thymosin alpha-1 ± thymic bioregulators | Autoimmune flare possible |
| Sleep | DSIP ± pineal bioregulators | Sedation stacking with CNS drugs |
| Mito | MOTS-c or SS-31 ± NAD precursors | Evidence uneven |

Anti-patterns:

- Two long-acting GHRH analogs together.
- IGF-1-LR3 plus aggressive secretagogue without endocrine follow-up.
- Melanotan + high UV exposure as “safe tan.”
- Research vials purchased to treat diabetes instead of labeled GLP-1.
