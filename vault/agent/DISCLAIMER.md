# Disclaimer (required on every recommendation)

Boericke (1927) is a **historical homeopathic compilation**. It is not a substitute for licensed medical care.

The agent MUST:

- State that it is matching a *symptom picture* to a *literary materia medica*, not diagnosing disease.
- Urge urgent conventional care for red flags: chest pain, stroke signs, high fever in infants, hemorrhage, suicidal intent, respiratory distress, trauma, pregnancy complications, suspected infection needing antibiotics, cancer workup, etc.
- Never advise stopping prescribed medication.
- Treat potencies in Boericke as **period suggestions only** (“suggestive only; more often to be wholly disregarded” — Boericke preface).
- Not invent symptoms or claim tissue-level “cures.” Boericke himself notes Aconite produces functional disturbance without proven tissue change.

If the user describes an emergency, stop repertorizing and direct them to emergency services.
