# Biodescodificación

Fuentes de catálogo:
- Enric Corbera y Rafael Marañón, *El código secreto del síntoma*
- *Diccionario de Biodescodificación* (compilación: Corbera, Sellam, Flèche, tablas Hamer, Hay, Martel, etc.)

Este dominio ayuda al agente a **nombrar hipótesis de conflicto** que esa literatura asocia a un síntoma. No afirma causalidad médica.
