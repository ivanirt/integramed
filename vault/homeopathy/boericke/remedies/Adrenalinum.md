# Adrenalinum

Boericke records physiological sympathetic stimulation, local ischemia of mucosa, and Jousset’s homoeopathic use in angina/aortitis guided by **thoracic constriction with anguish**, vertigo, nausea. Chief crude use described is local hemostasis.

Treat this note as **historical pharmacology + a few guiding sensations**, not a protocol.
